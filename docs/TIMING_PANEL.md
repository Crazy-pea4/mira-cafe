# 语音耗时面板

页面右上角的“语音耗时”开关默认收起。展开后可以查看最近的识别、模型、合成及播放阶段，关闭不影响当前对话；手机面板支持内部滚动。无需开启录音或额外调用模型来打开面板。

## 显示内容和边界

所有时间都由浏览器的单调时钟performance.now采集，是当前页面看到的链路时间，包含网络、代理和客户端处理，不能当作服务商纯推理时延。

| 指标 | 起点与终点 |
| --- | --- |
| ASR连接就绪 | 创建本次语音识别连接 → 收到ready |
| 识别等待 | 发送asr.commit → 收到最终结果并完成转写校验；不包含整段讲话时间 |
| 模型首字 | 模型HTTP请求开始 → 首次非空SSE文字预览；预览仍可能因校验修正而改变 |
| 完整回复 | 模型HTTP请求开始 → 收到最终合法回复；包含服务端生成、校验及有限格式修正 |
| TTS首包 | 创建本句合成连接 → 收到第一块非空、偶数字节的PCM；不是ready消息 |
| 音频接收完成 | 创建合成连接 → 收到done；不代表已经播完 |
| 本句开播等待 | 请求播放本句 → 播放器实际开始回调；真实PCM使用AudioContext播放时钟 |
| 本句总耗时 | 请求播放本句 → 本句播放器完成；包含等待和播放 |
| 最近回复首声 | 同轮模型请求开始 → 该轮第一次实际开播；包含校验、可能的剧情旁白和语音准备 |

模型计时从等待已有控制请求同步之后、实际发起HTTP前开始，不包括输入前的思考、讲话或录音准备。ASR片段单独显示，不将其录音阶段编号强行当成回复轮次，也不把最近一次ASR与任意后续文字回复相加。

每句可能产生一条合成和一条播放记录；它们是两个观察阶段，不代表两次TTS收费。模型格式修正可能产生多个服务端尝试，页面这条模型记录仍是一次应用请求；面板不是账单或服务端精确请求计数。

## 状态与保存

- 每条记录显示进行中、已完成、已取消或失败，并注明真实链路、演示模式或配置待确认。
- 模式标签反映应用配置，替身验证仍属于替身，不能据截图标签把测试数字称作真实服务性能。
- 界面在当前页面内存保留最近20个阶段，已结束记录的数值异步写入SQLite，每身份/模式最近200条，不收集对白、识别原文、音频、Cookie、密钥或原始异常信息；不写localStorage；服务器只接收严格数值白名单，写入失败提示，不影响对话。清空面板只清当前显示，不删除数据库历史，刷新也不把旧时钟数据混入本页。
- 刷新页面清空面板显示。清空按钮只删除本页计时显示，不停止播放或重置剧情；旧回调不能重新插入被清空的记录。
- 已完成、已取消、失败及已淘汰记录不会被迟到回调修改。取消或失败不填充成功耗时；没有实际开播回调时，不将播放器resolve当作成功发声。
- 面板收起时仍记录有限阶段，展开可以查看刚才的调用；不会额外建立连接、请求模型或自动开启麦克风。

## 实现入口

- [interaction-timing.ts](../src/core/interaction-timing.ts)：有界内存记录、首次里程碑、结束状态和同轮首声计算。
- [transport.ts](../src/core/transport.ts)：HTTP/SSE首字与最终回复。
- [speech-transport.ts](../src/core/speech-transport.ts)：ASR提交、ready、TTS首包及连接结束。
- [scene-audio.ts](../src/core/scene-audio.ts)：实际播放回调、失败与取消。
- [TimingDebugPanel.tsx](../src/TimingDebugPanel.tsx)：开关、记录、状态和度量说明。

## 验证

Docker内39个文件387项测试、类型、两种生产构建及30项编译产物部署检查通过。新增8项测试覆盖识别时间排除录音、SSE首字与完整回复、首包与开播分离、取消后的迟到事件、清空/淘汰后不复活、隐私字段及默认关闭。最初TTS测试夹具误用奇数字节PCM，改为有效偶数字节后通过，未放宽产品计时条件。

真实页面使用HTTP/SSE和WebSocket替身、合成MediaStream与原生PCM播放器，验证文字及电话输入计时、取消、失败、清空、刷新和默认收起，覆盖1280×900、390×844、320×640、390×410。截图发现面板被对白层遮住及窄屏顶部文字拥挤后，修正层级和布局，复核面板命中测试、入口尺寸和截图。收费请求为0，未使用物理麦克风或扬声器；测试结果不能当成真实网络延迟基准。

本面板只提供当前页面观察，数值历史已持久化但尚无跨会话聚合指标或全局错误率。剧情轨迹已单独实现为明确开启的无声回放，见[剧情回放](STORY_REPLAY_PROPOSAL.md)，不等于ASR/模型/TTS统一追踪。
