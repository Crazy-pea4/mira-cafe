## 触发与优先级

| 姿态 | 当前触发 | 体验方式与边界 |
|---|---|---|
| 认真倾听 | 用户按住说话/演示输入时的listening状态 | 真实入口先授权麦克风；Mock按住“体验对白”不会录音。不是随机轮播 |
| 托腮思考 | 请求等待与待播放时的thinking状态 | 发送文字、点击建议或提交识别后等待回复；返回很快时停留较短 |
| 捂嘴笑 | 已开始呈现的action=laughing对白 | 真实模型根据玩笑语义选择，不保证一句示例必触发；Mock输入“讲个笑话逗你笑”可确定触发 |
| 惊讶 | 已开始呈现的action=surprised对白 | Mock相遇后的风吹照片回应；真实模型可在意外时选择 |
| 犹豫 | 已开始呈现的action=hesitant对白 | Mock手机消息、恐惧、草稿对白；真实模型可在迟疑时选择 |

倾听/等待优先于模型动作；语义姿态只在该句开始呈现后显示，旁白不偷播后续姿态。结束、出错、打断和重置回到基础待机；旧turn回调不能恢复旧姿态或建议。保留look-window与offer-photo及三原始情绪，不把所有relieved自动改成笑。

Zod白名单、DeepSeek系统prompt、完整JSON示例及剧情提示已同步。thinking/listening不是模型可输出动作；未知动作仍拒绝，原有最多两次格式修正规则未变。没有新预算/次数门槛。
