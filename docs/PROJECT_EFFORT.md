## 估算限制

- 文件时间只能证明发生过活动，不能证明整段持续工作，也无法覆盖全部阅读、思考与讨论。
- Agent执行、等待服务、测试和人工操作可能重叠，不能分别相加，无法据此拆分人工与Agent占比。
- 覆盖写入、复制、构建和早期格式调整可能集中改变时间戳；窗口划分也会包含短空档，因此提供范围。
- 约53.2小时是自然跨度，不能写成人工投入；历史“首版约25分钟Agent执行”也不代表全项目。
- 视频与后续发布仍会增加少量投入。72小时是否按时交付，须结合实际收题及提交时间判断。
