# HUD 折叠验收

用户要求：收起对白框，看到更多Mira立绘；展开后继续当前对话。

## 行为

- 默认展开；“收起对话”隐藏旁白、对白、三建议、输入和提示区，保留右下角“展开对话”。不重新挂载App，也不改变剧情。
- 草稿和当前内容保留，隐藏期间收到/播放的对白正常更新，展开显示最新内容。折叠本身不提交请求、不启动或重播音频；已在播放的回复继续。
- 录音准备、录音、识别或权限等待会失去当前输入所有权；折叠取消它们，迟到回调/松手不能提交。展开不会自行开启麦克风。
- 原生button，44px高度，aria-expanded/aria-controls，Tab可达，Enter与空格可用。角色和背景不随HUD显隐位移。

## 本次实际检查

全部为本地真实App + 假provider/假音频；隔离页面禁止AudioContext及getUserMedia硬件访问，没有付费API。截图左上角三个控件仅属于隔离验收页，不进入产品构建。

- 278项单测通过（29个文件），包括隐藏期间两句音频继续、最新字幕、反复切换不额外请求、假录音取消、迟到识别丢弃、待授权失效和展开手势不解锁音频。
- 桌面1280×900：角色矩形x=550.40625、y=27、w=576、h=864，折叠前后完全一致；背景均1280×900。草稿和三建议原样恢复。
- 手机390×844：角色矩形x=-11.6640625、y=55、w=446.6640625、h=670不变；背景均390×844。恢复按钮x=281.65625、y=788、w=94.34375、h=44，无横向溢出。
- 缩短视口390×410：恢复按钮y=354、h=44，仍在视口内；展开后对白区独立滚动，输入可达。此项模拟可见区域变化，不等于真机键盘测试。
- 键盘Enter和空格恢复成功，连续三组收起/展开后草稿仍在，假请求/音频计数均0。
- 发送一条假回复，进入“正在说话”后折叠；计数保持1次请求/1段假音频，回复继续完成，展开看到最新对白及新三建议。
- 假按住输入时折叠，再展开并松手：held=false，回到idle，计数仍1/1，没有发送隐藏录音或恢复采集。

未验收：用户实际操作、真机触摸/软键盘、真实麦克风、扬声器与模型响应质量。本轮不部署线上。
