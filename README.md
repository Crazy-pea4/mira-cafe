# 雨停之前 · Mira Café

与原创成年旅行摄影师 Mira 在雨夜咖啡馆相遇的移动端网页。文字或按住说话与她互动，回复带字幕和声音，情绪、姿态和照片/来信事件随已呈现剧情变化。

当前交付检查：2026-10-26，已开放[私密线上评审](https://iamm.xyz/mira)。核心 MVP 已实现，右侧四节点剧情时间线、自动保存/刷新续接与重置按钮已加入；对白框常驻，已移除折叠/展开状态与控件。真实剧情 A/B 路线各 10 轮走通；C 路线此前 5 轮走通。完整范围、真实测试失败与修复见 [最终交付验收](docs/RELEASE_ACCEPTANCE.md)，不以自动测试代替真人验收。

## 启动与体验

建议 Node 24，支持 Node 22.12+ 的 22 系列、24 系列或 26+。不需要数据库、Docker、账号或私人 API key。

```sh
npm ci --ignore-scripts && npm run dev
```

打开 http://127.0.0.1:5173/，API 在本机 3001。已有进程占用端口时先关闭相应旧实例。也可 `npm run build && npm start` 后打开 http://127.0.0.1:3001/。

没有配置时自动进入标注清楚的“演示模式”。文字输入、三个回应建议、完整剧情、角色状态和打断均可体验。“体验对白”发送示例，不使用麦克风。演示朗读使用浏览器中文声音；没有声音时保留字幕。

本机现有入口：[真实配置版本](http://127.0.0.1:3001/) / [无收费 Mock 版本](http://127.0.0.1:3002/)。线上私密评审目标为 https://iamm.xyz/mira ，实时开放状态和版本见 [部署状态](docs/DEPLOYMENT_STATUS.md)。

## 可玩内容

- 三幕摄影委托故事，支持闲聊、自由新方案和拒绝；结局为诚实出发、协商后决定、婉拒并邀请练习。
- 照片被风吹到手边、旅馆来信、展示回信草稿、虚构发送和环境变暖。手机只是叙事道具，不真实发送消息。
- 新增剧情场景切换：首次讲到摄影委托时，从雨夜咖啡馆淡入照片里的山间旅馆；开始练习、展示草稿或发送回信时回到咖啡馆。这是随讲述展开的想象画面，不把玩家实际传送到旅馆。转场可打断，已完成的场景随剧情存档；图片失败保留咖啡馆并可重试。当前为本地新增，尚未发布线上，见 [场景切换](docs/SCENE_TRANSITION.md)。
- 待机、倾听、思考、说话和失败状态。基础三表情与局部眨眼/说话开合；倾听、托腮思考、捂嘴笑、惊讶、犹豫五套完整上半身姿态。
- 同一轮回复给出三个建议，完整呈现后才更新；暖金色发亮的选项可推进剧情，其余保留自由交流。未结束的剧情保留明确前进路径；自由输入与点击使用同一套判断，结合模型语义、已知事实和前置条件，每轮最多一个新事实。
- 右侧时间线按已呈现事实显示相遇、照片/来信、心事和回信。未来节点不剧透；短视口仅显示当前节点；不支持跳章或回退剧情。
- 对白、旁白和输入区始终可见；手机短视口保留内部滚动和输入空间。已呈现并确认的剧情自动保存到 localStorage；刷新或重新打开后恢复对白、道具、建议与时间线，并续接对话上下文。右上角“重置剧情”确认后清除存档并回到开场。

表演采用静态关键帧、局部贴图与 CSS 动画；新姿态不叠旧脸部蒙版。嘴型随播放状态开合，未实现音素同步、骨骼或连续逐帧动作。选用“其他角色动画”作为题目多模态路线，没有接入视频或对话中动态生成媒体。美术最终效果仍需用户验收。见 [角色姿态](docs/POSES.md)、[当前素材](public/characters/mira/README.md)。

Live2D 取舍（2026-10-26）：用户决定本次 Demo 暂不接入 Live2D，这是演示范围与投入的主动取舍，并非技术不可行。现有角色状态、情绪动作、TTS 和打断链路可作为接入基础；但保留 Mira 外观需要额外完成分层素材、Cubism 模型绑定、动作制作及移动端验证，复杂度超出当前短篇演示的需要。当前保留上述基础角色动画；后续需要提升连续表演时，再评估 Live2D。此项目前仅完成方案评估，未进行实际接入验证。

ComfyUI按用户决定仅预留服务端接口适配层：支持工作流参数绑定、提交、状态查询、图片下载、超时与取消等待；可删除指定排队任务，运行中不冒充已停止。`npm run demo:media`可离线验证Mock接口，不安装ComfyUI、Docker或模型。当前聊天页面未接入生图，服务器不启用；示例工作流含模型占位符，尚未真实联调，不标记为已完成动态生图或ComfyUI实操验收。配置、代码入口和后续步骤见 [ComfyUI适配说明](docs/COMFYUI_ADAPTER.md)。

## 系统结构与取舍

| 层   | 实现                         | 主要职责                               |
| ---- | ---------------------------- | -------------------------------------- |
| 页面 | React 19、TypeScript、Vite 7 | 场景、角色、字幕、输入和时间线         |
| 后端 | Node、Fastify 5              | 内存会话、同源 API 和语音 WebSocket    |
| 契约 | Zod 4 与共享 TypeScript      | 严格白名单、轮次、演出和呈现回执       |
| 文字 | DeepSeek / Mock              | 自由对话、情绪动作与剧情提议           |
| 语音 | Qwen 实时 ASR/TTS            | 16k PCM 输入、24k PCM 输出             |
| 剧情 | 模型提议 + 本地作者规则      | 前置条件、关键事实兜底、结局和道具演出 |

`src/core/engine.ts` 管理轮次与演出；`audio.ts`、`pcm-playback.ts` 管理播放器；`microphone.ts`、`voice-input.ts` 管理采集与识别；`src/StoryTimeline.tsx` 只读取已呈现剧情。

`server/app.ts` 管理会话和呈现回执，`providers.ts` 和 `qwen.ts` 连接服务。`story.ts` 保存已讲事实，`shared/story-progression.ts` 统一推进意图、前置条件和选项提示；`story-author.ts` 在玩家询问/愿意继续、模型已识别合格剧情方向却未讲完整时补齐该事实，`stage-director.ts` 执行白名单道具演出。真实配置每轮仍请求DeepSeek，兜底内容属于本地剧本，不冒充模型原文；闲聊或明确暂停不强推，结局需要用户建议，不靠固定轮数解锁。

采用轻量单页、单个 Node 服务、PNG 分层和按住说话，使 72 小时题目范围内的取消、失败恢复与移动端闭环可审查。内存最多 100 个会话，30 分钟清理；浏览器保存服务端签名的剧情检查点，可在内存清理、服务重启或重新登录后恢复。没有完整账号、数据库或大规模基础设施。

存档限当前浏览器、当前站点和路径，不跨设备同步；清除浏览器数据会删除它。正在生成或尚未播完的一句不会写入，刷新回到最近确认的位置，不自动重播语音。浏览器禁止存储时会提示，但仍可继续对话。

## 语音、字幕与打断

本地新版文字模型与页面已改为流式：DeepSeek 增量输出通过服务端 SSE 到达字幕区，生成时逐步显示；打断、断流和格式修正会清理未确认文字。完整回复通过结构及剧情校验后才执行动作、按句播放语音并接收呈现回执，生成预览不进入历史或存档。语音播放阶段仍为句级字幕，不宣称字级语音时间戳同步。本地替身端到端验证通过，真实服务新链路、线上发布和录屏仍未覆盖，见 [流式回复](docs/STREAMING.md)。

本地新版增加输入栏最右侧电话图标：点击并允许麦克风后持续监听，停顿后自动提交，可直接开口打断；红色电话挂断。通话有状态与计时，短促附和采用有限白名单过滤。原按住说话保留；通话中暂停该按钮。无真实语音配置时电话禁用，不冒充通话。此项尚未发布线上，使用与验证边界见 [实时语音通话](docs/VOICE_CALL.md)。

真实入口先点击“启用麦克风”授权，再按住说话，松开识别。权限申请本身不上传音频。按住方式使录音边界明确，避免自动 VAD 的误触发和回声问题。

首次可信交互只解锁播放，不自动欢迎、录音或请求模型。正常回复默认有声；浏览器限制声音、TTS 故障时显示提示并保留可取消字幕，不自动重新收费合成。字幕按句推进，以实际 PCM 播放时钟开始呈现；降级字幕按长度估时。

新输入和打断同步增加 turnId，停止播放、终止请求并清空未执行字幕/动作/道具。服务端保留取消水位；旧响应或旧取消不能覆盖新轮次。只有实际完成的句子和道具回执进入后续剧情；跨两段的同一事实累计后确认，结局决定讲完后才虚构发送。

切换页签或窗口不会中断正在请求、呈现或播放的回复，后台继续完成并自动保存；麦克风采集和识别在失焦/后台时结束，切回不会自动录音。离开页面或关闭场景时清理活跃回复与音频。客户端请求超时 21 秒，服务端 18 秒。

电话模式同样在失焦/后台暂停收音，保留已开始的回复；返回后点击电话继续。主动挂断则停止回复。能量VAD与浏览器回声消除仍需真实设备确认；不将短附和白名单声称为完整语义判断。语音断线后手动重连，不自动重新发送录音或收费请求。

## 结构化指令与失败恢复

```json
{
  "segments": [
    {
      "text": "风景不会看着我，等我说下一句。",
      "emotion": "guarded",
      "action": "hesitant",
      "beat": "fear"
    }
  ],
  "story": { "intent": "engage" },
  "suggestions": ["拿我练习一下，你会怎么问？", "能看看你的草稿吗？", "先视频沟通，再决定去不去。"]
}
```

模型每轮 1–2 段，合计最多 120 字。emotion 为 guarded / curious / relieved；action 为 idle / look-window / offer-photo / laughing / surprised / hesitant；倾听和思考由交互状态决定。模型不能指定任意 URL、脚本或外部媒体。旁白独立显示，不送入 Mira 的 TTS。

结构不合格最多修正两次，每次独立收费；网络、鉴权、余额、超时和内容过滤不盲目重试。耗尽后保留明确手动重试入口。建议不合格走本地情境回退，不为建议单独收费。诊断只记录白名单结构信息，不保存用户原始音频或密钥。

## 真实服务配置与用量

参考 [.env.example](.env.example) 和 [配置说明](docs/LIVE_SETUP.md)。默认关闭真实 API；仅填写 key 不会启用，需要显式设置 `MIRA_ENABLE_LIVE_APIS=true`、`MIRA_PROVIDER=deepseek`、`MIRA_SPEECH_PROVIDER=qwen` 后运行 `npm run start:configured`。普通启动不加载 .env。

使用 DeepSeek `deepseek-flash`，北京百炼 `qwen3-asr-flash-realtime` / `qwen3-tts-flash-realtime`，预置千雪 Chelsie 音色，不做克隆。密钥仅在服务端，.env、私密邀请文件、音频和诊断均不进 Git。

按用户决定，产品没有本地金额或累计请求拦截。`.local/budget.json` 仅尽力统计历史次数，不代表余额或实际账单，损坏也不阻断已配置服务。自动收费验收另有固定上限与防重放记录，不随用户日常使用继续运行。

## 来源、投入与剩余边界
