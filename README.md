## 打断与字幕

每次输入先同步递增 turnId，再 abort 旧请求、停止播放器、清空待执行字幕与动作。服务端按 sessionId 维护最新轮次，拒绝旧请求；取消通过 throughTurnId 水位处理，晚到的旧取消不能误伤新轮次。

网络结果、播放开始回调和每个异步继续点均检查轮次。即使 Provider 忽略 abort，旧内容也不能重放。服务端 18 秒超时，客户端 21 秒超时。

短回复完整通过 Zod 校验后分句播放。在音频 onstart 时才显示对应句子并触发该段动作；静音或朗读失败时使用可取消字幕时间线。字幕当前按句推进，没有精确逐字时间戳；降级按文字长度估时。只把完整呈现的助手句子写入后续历史。已经展示的照片可保留，未展示的事件被打断后不再出现。

按住模拟语音立即进入倾听，松开提交预设台词。真实 ASR 代码采用按住说话/松开提交，本机真实服务可用时自动选择真实入口，先准备权限再按住；暂不做自动 VAD。

## 结构化指令

```json
{"segments":[{"text":"这张照片，是我今晚等待的原因。","emotion":"curious","action":"offer-photo","event":"reveal-photo"}]}
```

emotion：guarded / curious / relieved；action：idle / look-window / offer-photo；可选 scene：rain / warm；可选 event：reveal-photo。真实模型每次 1–2 段、对白总计最多 120 字，必须有非空自然对白并通过严格 Zod 白名单校验；渲染器兼容范围仍为 1–3 段、每段最多 180 字。格式/空对白/截断不合格时携带净化后的字段错误最多修正 2 次（总 3 次），每次独立计入原预算；耗尽才显示错误，不再把非法指令静默降级当成功。网络、权限、余额、超时和过滤不按格式失败重试。只将 text 分句交给语音层，不朗读 JSON，不执行外部媒体 URL 或任意代码。
